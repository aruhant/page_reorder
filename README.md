# PDF Organization Software for GyanMandir

This software is designed for Jain Research Centre GyanMandir to manage, organize, catalogue, digitize, and restore their vast collection of manuscripts.



## Features

- PDF management for cataloguing scanned manuscript collections  
- Basic manipulation tools:
  - Reorder pages  
  - Resize individual or multiple pages  
  - Compress PDFs for efficient storage  
  - Add annotations (notes or highlights)  
- Restoration features:
  - De-skew tilted scans  
  - Reduce visual noise and blemishes
